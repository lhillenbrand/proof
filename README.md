# Proof

A feed of stories, quotes and speeches from people who went through hard things and came out the other side. Built to scroll instead of Instagram.

## What's here
- `index.html`: the app
- `cards.js`: the content library. Add or edit cards here. Every card needs a real, checkable source.
- `manifest.webmanifest` and `icons/`: make it installable to your home screen
- `sw.js`: lets it work offline. Bump `VERSION` when you change anything so phones pick up the update.

## Install on iPhone
Open the site in Safari, tap Share, then Add to Home Screen.
